# 💵 Calculadora de Gorjetas (Tip Calculator)

> Uma aplicação web prática e intuitiva desenvolvida para calcular o valor da gorjeta e dividir o total da conta de forma justa entre várias pessoas.

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido com foco na aplicação prática de **JavaScript moderno (ES6+)**, manipulação de formulários, tratamento de eventos e atualização dinâmica do DOM. A aplicação resolve um problema cotidiano comum: calcular rapidamente a porcentagem de serviço desejada e o valor final por pessoa.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica da interface e campos de entrada.
* **CSS3:** Estilização visual, layout centralizado e design responsivo.
* **JavaScript (ES6+):** Lógica de cálculo matemático, validação de entradas e manipulação do DOM.
* **Git & GitHub:** Controle de versão e hospedagem do código.

---

## ⚙️ Funcionalidades
* **Cálculo dinâmico:** Processa o valor da conta, a porcentagem da gorjeta e a quantidade de pessoas.
* **Divisão de contas:** Informa exatamente quanto cada pessoa deve pagar (conta + gorjeta divididas).
* **Validação de campos:** Garante que os valores inseridos sejam válidos antes de realizar os cálculos.
* **Interface Responsiva:** Layout adaptado para diferentes tamanhos de tela.
